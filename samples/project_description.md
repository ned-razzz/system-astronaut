# Uhlanga Project Description

## 프로젝트 개요

Uhlanga는 메이플스토리 월드의 **메이플 플래닛**에서 플레이어처럼 상황을 판단하고
행동하는 자동 플레이 시스템을 연구·구현하는 개인 실험 프로젝트다. 핵심 연구 질문은
자동 플레이의 행동이 사람의 플레이와 얼마나 비슷해질 수 있는가이다. 정해진 동작의
반복에 그치지 않고, 상황에 맞는 목표와 행동을 선택하며 같은 상황에서도 사람과 같은 
자연스러운 행동으로 동작하는 것을 목표로 한다.

## 전체 제품 방향

장기적으로 캐릭터 생성부터 성장과 사냥까지 이어지는 플레이를 자동화한다. 캐릭터가
이동하고 퀘스트를 수행하며 장비·스킬·스탯을 관리하고, 성장 단계에 맞는 사냥터를 찾아가서
자기 캐릭터 직업에 맞는 스킬을 사용하여 몬스터들을 사냥하는 것이 목표다. 

게임 자체에서 매크로를 방지하기 위한 거짓말탐지기 기능을 우회하기 위한 거탐 탐지 및 풀이 기능을
구현해야 한다. 거짓말탐지기 종류에는 퀴즈, 움직이는 도형 따라가기가 있다.

여러 PC에서 해당 자동화 기능을 돌릴 때 각 자동화 상태를 실시간으로 모니터링하고 
24시간 연중무휴로 운영할 수 있어야 한다. 해당 기능은 다른 담당자가 구현할 것이기 때문에
일단 설계만 해두고 이후에 완성된 기능을 통합할 것이다.

시간이 남는다면 다른 플레이어의 등장과 채팅에도 상황에 맞게 대응하는 기능도 구현할 계획이다.

## MVP 구현 범위

첫 단계에서는 사냥터에 배치된 모험가 썬콜 캐릭터의 자동사냥을 다룬다. 대상 사냥터는
헤네시스 동쪽 언덕, 개미굴1, 빨간코해적단1이다. 지형이 서로 다른 세 곳에서 공통 자동사냥
기능을 사용할 수 있는지 확인한다.

자동사냥의 핵심 사용자 목표는 캐릭터가 사냥터에서 이동하고 주력 공격 스킬과 HP·MP
물약을 사용하며, 사용자 개입 없이 사냥을 이어 가는 것이다. 실행할 사냥터를 지정할 수
있어야 한다. 사냥 속도나 시간당 처치 수에는 합격선을 두지 않는다.

각 사냥터에서 서로 다른 날에 1시간 무개입 실행을 3회 수행하고, 실행 중 캐릭터가
사망하지 않으며 사냥이 지속되는 것을 초기 검증 목표로 삼는다. 같은 상황에서도 목표
선택, 이동, 공격 방식이 상황에 맞게 달라지는 행동 다양성도 연구 범위에 포함한다.

일시적으로 사냥 대상이나 필요한 상태를 파악하지 못한 뒤 다시 판단할 수 있게 되면
사냥을 재개한다. 계속 행동했을 때 결과를 예측하기 어려우면 조작을 멈추고 사용자에게
알린다. 사용자는 실행 결과와 중단 사유를 확인할 수 있어야 한다.

## 사람 유사성 평가

사람 유사성은 입력 시점에 무작위 변화를 주는 것만으로 평가하지 않는다. 목표 선택,
이동, 공격 위치와 시점, 입력 행동이 상황에 맞으면서도 다양하게 나타나는지를 사람의
플레이와 비교한다. 사냥 지속성과 실패 결과는 사람 유사성 평가와 구분해 살핀다.
평가 지표와 합격 기준은 사용자 요구사항에서 구체화한다.
