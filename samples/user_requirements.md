# Uhlanga User Requirements

| ID | name | User story | Acceptance Criteria | State |
|---|---|---|---|---|
| UR_01 | 자동 사냥 | 사용자는 캐릭터를 직접 조작하지 않고도 사냥을 계속할 수 있도록, 캐릭터가 사냥터 스테이지에서 알아서 몬스터를 사냥하기를 원한다. | • 현재 사냥터를 자동으로 식별하고 이동·공격·HP·MP 물약 사용으로 사냥을 이어 간다.<br>• 몬스터가 일시적으로 보이지 않거나 인식에 실패해도 상황을 다시 파악하면 사용자 개입 없이 사냥을 재개한다.<br>• 계속 조작한 결과를 예측하기 어려우면 자동 입력을 중지하고 사용자에게 사유를 알린다. 중단된 실행은 무개입 사냥 실패로 기록한다. <br>• 거짓말탐지기 대응을 포함하여 24시간 연속으로 사용자 개입 없이 사냥을 이어 간다. | confirmed |
| UR_02 | 자동 성장 | 사용자는 캐릭터가 목표 사냥터에서 자동 사냥할 준비를 직접 하지 않아도 되도록, 캐릭터 생성부터 목표 스테이지까지의 성장 과정을 자동으로 끝내기를 원한다. | • 모든 핵심 사냥터와 사냥에 유리한 일부 직업을 지원하며, 해당 직업이 목표 사냥터에 도달하는 데 필요한 성장 과정을 지원한다.<br>• 사용자 조작 없이 새 캐릭터를 생성하고 스테이지를 이동하며, 성장에 필요한 퀘스트를 수주·수행·완료한다.<br>• 사냥과 퀘스트로 레벨을 올리고, 성장 단계에 맞게 장비를 관리하고 스킬과 스탯을 배분한다.<br>• 성장 단계에 따라 사냥터를 옮기며, 목표 스테이지에 필요한 성장과 준비를 마치면 해당 스테이지에서 자동 사냥을 시작한다.<br>• 프로그램이 24시간 연속으로 사용자 개입 없이 캐릭터의 성장과 이후 사냥을 수행한다. | confirmed |
| UR_03 | 사람처럼 플레이 | 사용자는 캐릭터를 조작하는 키 입력이 사람이 직접 조작하는 것처럼 자연스럽도록, 프로그램이 사람과 유사한 불규칙하고 다양한 입력 패턴으로 키를 조작하기를 원한다. | • 사냥과 성장 중 키를 누르고 떼는 시점, 누르는 시간과 입력 간격이 사람의 입력 패턴과 유사하다.<br>• 같은 작업을 반복해도 고정된 입력 패턴만 되풀이하지 않고, 불규칙하고 다양한 키 입력으로 캐릭터를 조작한다. | confirmed |
| UR_04 | 관제 및 알림 | 사용자는 여러 PC의 프로그램이 정상적으로 작동하는지 확인하고 대응이 필요한 상황을 알 수 있도록, 전체 PC와 각 PC의 작동 상황을 안정적으로 모니터링하고 작동 중지나 이벤트 발생 시 알림을 받기를 원한다. | • 한곳에서 여러 PC의 실행 여부, 현재 활동과 중단·실패 상태를 함께 확인할 수 있다.<br>• 각 PC의 게임 화면과 프로그램 실행 상태를 개별적으로 확인할 수 있다.<br>• 화면과 상태 반영에 시차가 생기더라도 안정적으로 끊김 없이 모니터링을 지속할 수 있다.<br>• 프로그램의 작동이 중지되거나 알림 대상 이벤트가 발생하면, 해당 PC와 발생 내용을 식별할 수 있는 알림을 받는다. | confirmed |
| UR_05 | 거짓말탐지기 회피 | 사용자는 거짓말탐지기가 나타나도 직접 문제를 풀 필요 없이 플레이를 이어 갈 수 있도록, 프로그램이 발생을 인식하고 문제를 자동으로 풀기를 원한다. | • 사냥 또는 성장 중 거짓말탐지기가 작동하면 자동으로 인식한다.<br>• 퀴즈와 움직이는 도형 따라가기 등 제시된 문제를 사용자 개입 없이 풀고 필요한 응답을 제출한다.<br>• 문제를 해결한 뒤 일시 차단 없이 프로그램이 캐릭터의 사냥 또는 성장을 재개한다. | confirmed |

## Pending Product Decisions

- UR_02: 모든 핵심 사냥터와 사냥에 유리한 일부 직업을 지원한다는 범위에서, 핵심 사냥터·지원 직업의 구체 목록과 각 직업의 성장 경로·필수 퀘스트·최종 목표 스테이지.

## Excluded Scope

- UR_06: 다른 플레이어 등장과 채팅에 대한 대응은 부차적이고 효용성이 불분명하며 구현 난이도가 높아 현재 제품 범위에서 제외한다.
