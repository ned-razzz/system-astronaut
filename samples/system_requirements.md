# Uhlanga System Requirements

## Features

### SR_01 화면 인식

| Item | Content |
|---|---|
| Overview | 프로그램은 게임 화면에서 캐릭터·지형·몬스터와 각종 게임 정보를 인식하여 현재 상황을 이해한다. 화면 변화에 따라 인식 정보를 갱신하고, 확인된 정보와 인식할 수 없는 정보를 구분한다. |
| State | confirmed |
| Priority | must |
| Source UR | UR_01, UR_02 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 스테이지와 지형 인식 | 프로그램은 게임 화면에서 현재 스테이지를 식별하여 스테이지 간 이동 경로상 현재 위치를 특정하고, 캐릭터가 이동할 수 있는 지형인 발판, 로프, 포탄을 파악해야 한다. 각 지형 요소의 위치와 연결 관계를 구분하여 이동 가능한 공간을 이해해야 한다. |
| 02 | 엔티티 인식 | 프로그램은 조작 대상 캐릭터, 몬스터와 주요 NPC를 구분하고 화면 내 위치를 파악해야 한다. 갱신된 화면에서 이들의 위치와 상태 변화를 파악하고, 몬스터의 탐지 여부와 처치 판단에 필요한 정보를 제공해야 한다. 화면에서 몬스터가 사라진 사실과 처치가 확인된 상태를 구분해야 한다. |
| 03 | 게임 상태 정보 인식 | 프로그램은 화면에 표시된 캐릭터의 직업·레벨·HP·MP, 보유 물약과 구매에 사용할 재화, 퀘스트 진행·완료 상태, 장비와 스킬·스탯 및 배분 가능한 포인트 정보를 파악해야 한다. 게임 조작으로 화면이 바뀌면 해당 정보를 갱신해야 하며, 표시되지 않거나 판독할 수 없는 정보는 확인된 값과 구분해야 한다. |

### SR_02 마우스 및 키보드 조작

| Item | Content |
|---|---|
| Overview | 프로그램은 게임에서 수행할 행동을 마우스와 키보드 입력으로 실행한다. 입력 순서·시점·지속 시간을 제어하고, 행동 변경이나 중단 시 기존 입력을 종료한다. |
| State | confirmed |
| Priority | must |
| Source UR | UR_01, UR_02, UR_03, UR_05 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 키보드 조작 | 프로그램은 이동·공격·물약 사용과 게임 화면 조작에 필요한 키 누르기·유지·해제를 수행해야 한다. 행동에 필요한 키 조합과 입력 순서, 입력 시점·지속 시간·간격을 제어할 수 있어야 한다. |
| 02 | 마우스 조작 | 프로그램은 게임 화면의 지정된 위치로 마우스 포인터를 이동하고, 필요한 버튼 누르기·유지·해제와 클릭·드래그·스크롤을 수행해야 한다. 행동에 필요한 이동 위치와 입력 순서·시점·지속 시간을 제어할 수 있어야 한다. |
| 03 | 입력 실행과 종료 관리 | 프로그램은 수행할 행동에 맞춰 마우스와 키보드 입력을 순서대로 또는 함께 실행해야 한다. 행동이 변경되거나 중단되면 이전 행동의 진행 중인 입력을 종료하고 예정된 입력을 취소하며, 누르고 있던 키와 마우스 버튼을 해제하여 이전 조작이 계속되지 않도록 해야 한다. |

### SR_03 자동 사냥

| Item | Content |
|---|---|
| Overview | 프로그램은 사냥 상황에 따른 행동 정책으로 대상을 탐색하여 이동·공격을 반복한다. 사용자가 중단하거나 복구할 수 없는 문제가 발생할 때까지 사냥을 지속하며, 물약이 부족하면 자동으로 구매하고 사냥에 복귀한다. |
| State | confirmed |
| Priority | must |
| Source UR | UR_01 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 행동 정책 | 프로그램은 화면 인식으로 파악한 캐릭터·몬스터·지형·HP·MP 상태와 직업별 사냥 기준을 바탕으로 사냥 대상을 선택해야 한다. 대상에게 접근할 필요가 있으면 공격 가능한 위치까지 이동 경로를 탐색하고, 마우스·키보드 조작으로 이동·공격·물약 사용을 수행해야 한다. 대상을 찾지 못하면 탐색을 이어 가고, 몬스터를 처치하면 다음 대상을 탐색해야 한다. 조작 후 변화한 상황에 따라 다음 행동 또는 사냥 중단을 결정하며 사냥을 반복해야 한다. |
| 02 | 사냥 중단 | 프로그램은 사용자가 중단을 요청하거나 복구할 수 없는 문제가 발생하면 사냥을 중단해야 한다. 대상을 계속 찾지 못하면 탐색·위치 변경으로 복구를 시도하고, 복구할 수 없으면 중단해야 한다. 중단 시 진행 중인 사냥 입력을 종료하고 예정된 사냥 입력을 취소하며 눌린 키를 해제해야 한다. 사용자 요청과 문제로 인한 중단을 구분하여 사유를 기록해야 한다. |
| 03 | 물약 보충과 사냥 복귀 | 프로그램은 HP·MP 물약이 부족하면 사냥을 일시 중지하고 현재 위치에서 가까운 물약 상점으로 이동해야 한다. 지원 스테이지 간 이동 경로와 상점 위치를 파악하여 PC별로 설정된 종류와 보충량에 맞춰 물약을 구매하고, 구매 결과를 확인한 뒤 기존 사냥터로 돌아가 사냥을 재개해야 한다. 재화 부족 등으로 구매할 수 없으면 작업을 중지하고 사유를 알려야 한다. |

### SR_04 자동 성장

| Item | Content |
|---|---|
| Overview | 프로그램은 새 캐릭터를 생성하거나 기존 캐릭터의 현재 성장 상태에서 시작하여, 정해진 성장 경로에 따라 스테이지 이동과 퀘스트를 수행한다. 직업과 성장 단계에 맞춰 스탯·장비·스킬을 관리하고, 목표 사냥터에서 자동 사냥하며 성장을 반복한다. 지원 범위는 모든 핵심 사냥터와 사냥에 유리한 일부 직업이다. |
| State | confirmed |
| Priority | must |
| Source UR | UR_02 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 캐릭터 생성과 성장 시작 | 프로그램은 사용자가 선택한 지원 직업과 최종 목표 사냥터에 맞춰 성장을 시작해야 한다. 새 캐릭터를 생성하는 경우 사용자 조작 없이 생성하여 게임에 진입해야 하며, 기존 캐릭터를 사용하는 경우 현재 성장 상태를 파악하여 해당 단계부터 성장을 이어 가야 한다. |
| 02 | 성장 경로 진행 | 프로그램은 화면 인식으로 파악한 현재 성장 상태와 실행에 적용된 환경 설정의 직업별 성장 경로를 바탕으로 다음 목적지와 수행할 작업을 결정해야 한다. 목적지까지 이동 경로를 탐색하고, 마우스·키보드 조작으로 이동·퀘스트·장비 착용·스탯 및 스킬 배분을 수행해야 한다. 목적지 도착과 작업 결과를 확인하여 다음 성장 단계로 진행하고, 사냥이 필요한 단계에서는 자동 사냥을 수행해야 한다. |
| 03 | 퀘스트 수주와 수행 | 프로그램은 현재 성장 단계에 필요한 퀘스트를 수주하고, 제시된 목표를 수행한 뒤 완료 처리와 보상 수령을 해야 한다. 퀘스트 진행 상태와 완료 결과를 반영하여 다음 퀘스트 또는 성장 단계로 진행해야 한다. |
| 04 | 직업별 스탯·장비·스킬 관리 | 프로그램은 실행에 적용된 환경 설정의 직업·성장 단계별 기준에 따라 획득한 스탯·스킬 포인트를 배분하고, 보유 장비 중 적합한 장비를 선택하여 착용·교체해야 한다. 레벨 상승이나 장비 획득으로 성장 상태가 바뀌면 현재 단계의 기준에 맞춰 배분과 장비 구성을 갱신해야 한다. 장비 구매·강화·판매·폐기는 현재 범위에 포함하지 않는다. |
| 05 | 목표 사냥터 이동과 성장 반복 | 프로그램은 현재 성장 단계의 목표 사냥터에 필요한 준비가 완료되면 해당 사냥터로 이동하여 자동 사냥을 시작해야 한다. 사냥으로 레벨과 성장 상태가 바뀌면 성장 경로의 다음 단계에 따라 이동·퀘스트·스탯·장비·스킬 관리를 반복해야 한다. 최종 목표 사냥터의 준비가 완료되면 해당 사냥터에서 자동 사냥을 이어 가야 한다. 전체 과정은 사용자 개입 없이 수행해야 한다. |

### SR_05 사람처럼 플레이

| Item | Content |
|---|---|
| Overview | 프로그램은 사냥과 성장에 필요한 키 입력을 사람과 유사한 불규칙하고 다양한 입력 패턴으로 수행한다. |
| State | confirmed |
| Priority | should |
| Source UR | UR_03 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 사람과 유사한 키 입력 | 프로그램은 사냥과 성장 중 키를 누르고 떼는 시점, 누르는 시간과 입력 간격에 사람의 입력에서 관찰되는 변동을 반영해야 한다. 입력의 변동은 수행할 이동·공격·성장 동작을 완료할 수 있는 범위에서 적용해야 한다. |
| 02 | 반복 작업의 입력 다양성 | 프로그램은 같은 작업을 반복할 때 고정된 키 입력 시퀀스와 시간 간격만 되풀이하지 않아야 한다. 작업에 필요한 조작을 유지하면서 입력 시점·지속 시간·간격에 불규칙성과 다양성을 반영해야 한다. |

### SR_06 거짓말탐지기 회피

| Item | Content |
|---|---|
| Overview | 프로그램은 사냥 또는 성장 중 거짓말탐지기의 발생을 인식하고 제시된 문제에 응답한 뒤 기존 활동을 재개한다. |
| State | confirmed |
| Priority | must |
| Source UR | UR_05 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 발생 인식과 대응 전환 | 프로그램은 사냥 또는 성장 중 거짓말탐지기의 발생을 자동으로 인식하고, 기존 활동의 입력이 문제 응답을 방해하지 않도록 해당 입력을 중지한 뒤 거짓말탐지기 대응으로 전환해야 한다. 대응 전 활동과 성장 단계를 유지하여 이후 복귀할 수 있어야 한다. |
| 02 | 문제 해결과 응답 제출 | 프로그램은 퀴즈와 움직이는 도형 따라가기 등 제시된 문제를 파악하고 사용자 개입 없이 문제 유형에 맞는 답과 조작을 수행해야 한다. 제한 시간이 있는 경우 해당 시간 내에 필요한 응답을 제출해야 한다. |
| 03 | 결과 확인과 활동 복귀 | 프로그램은 제출 후 문제 해결 여부와 일시 차단 여부를 확인해야 한다. 문제 해결 후 일시 차단 없이 대응 전 사냥 또는 성장 활동을 재개해야 한다. 응답에 실패하더라도 다시 풀 기회가 있으면 자동으로 재시도해야 한다. 더 이상 응답할 수 없거나 일시 차단이 발생하면 조작을 중지하고 실패 상태와 사유를 기록하여 사용자에게 알려야 하며, 이를 정상 복귀로 기록해서는 안 된다. |

### SR_07 관제 및 알림

| Item | Content |
|---|---|
| Overview | 프로그램은 여러 PC의 실행 현황과 개별 게임 화면을 한곳에서 안정적으로 확인할 수 있게 하고, 작동 중지와 알림 대상 이벤트를 사용자에게 알린다. 화면과 상태 반영의 시차를 허용한다. |
| State | confirmed |
| Priority | should |
| Source UR | UR_04 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 전체 현황과 개별 확인 | 프로그램은 PC를 구분할 수 있는 식별 정보와 함께 각 PC의 실행 여부, 현재 활동, 중단 사유와 실패 여부를 한곳에서 표시해야 한다. 프로그램을 열었지만 자동 성장이나 자동 사냥을 시작하지 않은 상태는 중단 상태로 표시해야 한다. 실행은 자동 성장 또는 자동 사냥을 시작하여 사용자 요청이나 복구 불가 문제로 작업을 종료하기까지의 수행을 의미한다. 실행 중 물약 보충·거짓말탐지기 대응·자동 복구를 위해 기존 입력이나 사냥을 일시 중지하더라도 실행 상태를 유지하고 현재 활동을 구분하여 표시해야 한다. 사용자가 PC를 선택하면 해당 PC의 게임 화면과 상태를 개별적으로 확인할 수 있어야 하며, 복구 중에는 현재 복구 시도 상태를 표시해야 한다. |
| 02 | 지속적인 모니터링 | 프로그램은 화면과 실행 상태를 지속적으로 갱신하여 장시간 안정적으로 모니터링할 수 있게 해야 한다. 각 정보의 마지막 갱신 시점을 표시하고, 갱신이 지연되거나 연결이 끊긴 PC를 정상 작동 중인 PC와 구분해야 한다. 한 PC의 연결 문제로 다른 PC의 관제가 중단되어서는 안 되며, 일시적인 연결 장애가 해소되면 사용자 개입 없이 해당 PC의 정보 갱신을 재개해야 한다. |
| 03 | 중지·이벤트 알림 | 프로그램은 각 PC의 작동 중지·실패, 복구 완료, 거짓말탐지기 발생과 처리 결과, 최종 목표 사냥터 도달을 감지하면 사용자에게 알림을 제공해야 한다. 알림에는 해당 PC, 발생 시점, 발생 내용과 확인 가능한 사유를 포함해야 한다. 통신이 일시적으로 끊겨 알림을 전달하지 못한 경우 연결 복구 후 전달하여 알림이 누락되지 않게 해야 한다. |
| 04 | PC별 실행 환경 설정 | 프로그램은 관제 화면에서 사용자가 각 PC의 환경 설정을 미리 지정하고, 실행 중에도 편집·저장할 수 있게 해야 한다. 설정에는 HP·MP 물약 종류와 보충량, 지원 직업, 최종 목표 사냥터, 사냥·성장 관련 설정과 직업·성장 단계별 장비 선택·착용 기준 및 스탯·스킬 포인트 배분 기준을 포함해야 한다. 자동 성장 또는 자동 사냥을 시작할 때 저장된 설정을 해당 실행에 적용해야 한다. 실행 중 저장한 변경값은 현재 실행에 영향을 주지 않고 다음 실행부터 적용해야 한다. 사용자는 현재 실행에 적용된 설정과 다음 실행에 적용할 저장된 설정을 구분하여 확인할 수 있어야 한다. |

### SR_08 복구 및 예외 처리

| Item | Content |
|---|---|
| Overview | 프로그램은 자동 사냥과 자동 성장 중 발생한 인식 실패·조작 실패·진행 불가 상태를 감지하여 복구를 시도하고, 복구 후 기존 활동을 재개한다. 복구가 불가능하거나 조작 결과를 예측하기 어려우면 입력을 중지하고 사유를 알린다. |
| State | confirmed |
| Priority | should |
| Source UR | UR_01, UR_02 |

| Sub-SR | Name | Requirement |
|---|---|---|
| 01 | 문제 감지와 복구 시도 | 프로그램은 자동 사냥과 자동 성장 수행 중 필요한 상태를 인식하지 못하거나 조작 결과가 예상과 다르거나 다음 단계로 진행할 수 없으면 문제 상태를 감지해야 한다. 문제가 발생한 활동과 성장 단계, 확인 가능한 원인을 보존하고 현재 상황을 다시 파악하여 문제 유형에 맞는 복구를 시도해야 한다. 복구 입력은 결과를 예측할 수 있는 범위에서만 수행해야 한다. 복구에는 행동 재시도와 캐릭터 사망 후 기존 사냥터 복귀를 포함한다. 게임 재접속과 재실행은 복구 범위에서 제외한다. |
| 02 | 복구 확인과 활동 재개 | 프로그램은 복구 후 현재 상태와 기존 작업의 완료 여부를 다시 확인해야 한다. 활동을 계속할 수 있으면 사용자 개입 없이 중단된 사냥 또는 성장 단계에서 수행을 재개해야 하며, 이미 완료된 캐릭터 생성·퀘스트 완료·포인트 배분을 완료 여부 확인 없이 반복해서는 안 된다. 문제 발생, 복구 시도와 재개 결과를 기록해야 한다. |
| 03 | 복구 불가 시 중지와 통보 | 프로그램은 정해진 복구 실패 조건에 도달하거나 계속 조작한 결과를 예측하기 어려우면 진행 중인 입력을 종료하고 예정된 입력을 취소하며 눌린 키를 해제해야 한다. 중지 상태에서는 자동 입력을 발생시키지 않아야 한다. 중지한 활동과 사유를 기록하고 사용자에게 알려야 하며, 해당 실행을 무개입 수행 실패로 기록해야 한다. 자동 사냥 중 중지된 실행은 무개입 사냥 실패로 기록해야 한다. |
