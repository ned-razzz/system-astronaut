# 사용자 요구사항

행사장에 설치하는 로봇 카페 서비스의 사용자 요구사항이다. 운영자가 카페 트럭의 이동, 가게 준비와 배치를 완료하고 테이블·픽업대·가게 바깥 모객 위치가 표시된 주변 지도를 준비한 이후의 자동 운영을 대상으로 한다.

| ID | name | User story | Acceptance Criteria | State |
|---|---|---|---|---|
| UR_01 | 키오스크로 상품 주문 | 카페 손님은 키오스크로 원하는 상품과 받을 테이블을 선택하여 카페 서비스를 이용하고 싶다. | ① 손님은 키오스크에서 원하는 상품들을 주문할 수 있다. ② 손님은 운영자가 등록한 테이블 중 상품을 받을 테이블을 키오스크에서 선택한다. ③ 주문이 접수되면 주문 상품과 선택한 테이블이 제조와 서빙 대상으로 이어진다. | confirmed |
| UR_02 | 주문 상품의 자동 준비와 테이블 서빙 | 카페 손님은 주문한 상품들을 지정된 테이블에서 받아 직접 상품을 가져오는 수고 없이 이용하고 싶다. | ① 주문이 들어오면 제조 로봇이 주문한 상품들을 순차적으로 준비한다. ② 핫도그는 제조 로봇이 직접 제조하고, 음료는 구비된 캔음료를 옮겨 준비한다. ③ 준비가 끝난 상품들은 픽업대에 놓이고, 서빙 로봇이 해당 주문 상품들을 자신의 트레이에 올린다. ④ 서빙 로봇은 손님이 선택한 테이블로 이동해 상품들을 서빙한다. ⑤ 운영 준비와 지도 준비가 완료된 뒤에는 주문 상품 준비와 서빙이 로봇들과 내재된 시스템으로 자동 진행된다. ⑥ 상품을 준비하거나 서빙할 수 없으면 해당 주문의 자동 진행을 중지한다. 손님은 키오스크에서 미완료 상태와 사유를 확인할 수 있고, 운영자는 해당 주문과 실패 내용을 식별할 수 있는 알림을 받는다. ⑦ 운영자는 중지된 주문을 재시도하거나 취소할 수 있다. 재시도 시 이미 완료된 제조·서빙을 중복 수행하지 않고 미완료 작업을 이어 가며, 취소하면 해당 주문의 추가 제조·서빙을 종료한다. | confirmed |
| UR_03 | 서빙 로봇을 통한 모객 | 카페 운영자는 손님이 적거나 직접 모객이 필요하다고 판단할 때 서빙 로봇으로 가게 밖에서 모객활동을 하고 싶다. | ① 미서빙 주문이 없고 서빙 로봇이 픽업대 대기 위치에서 5분 이상 연속으로 유휴 상태에 있으면 자동으로 모객 모드가 실행된다. ② 운영자는 미서빙 주문이 없고 로봇이 대기 중일 때 모객 모드를 직접 시작할 수 있다. ③ 모객 모드에서는 주변 지도에 운영자가 지정한 가게 바깥 모객 위치로 이동하여 카페 안내 음성을 1회 재생하고 상품 정보를 표시한 뒤 픽업대 대기 위치로 복귀한다. ④ 모객 위치 도착, 안내 음성 재생·상품 정보 표시와 복귀 완료 여부를 확인하여 활동 완료를 판단한다. 방문자 수나 주문 증가량에는 합격선을 두지 않는다. ⑤ 모객활동 중 새 주문이 접수되거나 운영자가 중지를 요청하면 모객활동을 중단하고 픽업대로 복귀한다. 새 주문이 있는 경우 모객보다 상품 서빙을 우선한다. | confirmed |

## Pending Product Decisions

현재 제품 수준의 미결정 사항은 없다.

## Excluded Scope

- 카페 트럭의 행사장 이동, 가게 준비와 배치의 자동화는 제품 범위에서 제외한다.
- 주변 지도 생성의 자동화는 제품 범위에서 제외한다. 운영자가 사전에 준비한 지도를 제공하는 것을 운영 선행 조건으로 한다.
